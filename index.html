      What MannAutomatedScanner Checks

      Comprehensive coverage of the most exploited HTTP security weaknesses.

      🛡️

      Content-Security-Policy

      Validates the presence and quality of CSP directives to prevent XSS and data injection attacks.

      🔐

      Strict-Transport-Security

      Checks for HSTS header with adequate max-age, includeSubDomains, and preload directives.

      🖼️

      X-Frame-Options

      Detects missing clickjacking protection to prevent embedding your site in malicious iframes.

      🚫

      X-Content-Type-Options

      Checks that MIME-type sniffing is disabled to block MIME confusion attacks.

      🌐

      CORS Wildcard Detection

      Flags Access-Control-Allow-Origin: * and dangerous credential combinations.

      🔑

      Permissions-Policy

      Audits browser feature access controls for camera, microphone, geolocation, and more.

      🔗

      Referrer-Policy

      Ensures sensitive URL data isn't leaked to third parties via the Referrer header.

      ⚠️

      CORS Method Exposure

      Detects dangerously permissive Access-Control-Allow-Methods like PUT and DELETE.

      How It Works

      Three clean steps from URL to actionable security report.

      1

      HTTP Request

      The Python script sends a crafted HTTP GET (and OPTIONS for CORS) request to the target URL using the requests library, capturing all response headers.

      2

      Header & CORS Analysis

      Each response header is matched against a curated ruleset. Missing headers, weak values, and dangerous CORS configurations are flagged with severity ratings.

      3

      Scored Report

      A human-readable report is generated with a security score, per-check pass/fail status, and prioritised recommendations you can act on immediately.

      Built with Python

      MannAutomatedScanner is a lightweight Python script that uses only the standard requests library. It can be run directly from the command line or exposed as a REST endpoint via Flask. No databases, no agents — just a clean audit of what your server is (and isn't) sending.

      The Flask API wraps the scanner and powers this frontend, accepting a URL via POST and returning structured JSON results. The entire tool can be self-hosted in minutes.

      Python 3.10+ Flask requests HTML5 CSS3 Vanilla JS
